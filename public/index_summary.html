Family Bank — index.html + app.js summary

Single-page, phone-friendly parent app. Static HTML/CSS/JS talking to Supabase (auth + Postgres with row-level security). Status: logged in, child picker, child view, record form, ledger with interest and settings all implemented. Browser-verified up to the first working screen; the ledger, interest and restyle were syntax-checked only (not yet browser-tested).

Data assumptions

  • children: id, name, family_id (differs from supabase/schema.sql, which says display_name/is_active).
  • parents: id, family_id, display_name. transactions and withdrawal_requests columns are assumed to follow plan.md; unverified against the live DB.
  • Balance = deposits + interest + adjustments − withdrawals (adjustments are always added, so negative corrections need a negative amount).
